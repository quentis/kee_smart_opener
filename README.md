# kee_smart_opener

## Reference documents

The datasheets and manuals are not stored in the repository, the table below links to the manufacturers' copies.
The one exception is the E07-433M20S user manual, which is hard to find online and is kept in
[`doc/`](doc/E07-433M20S_Usermanual_EN_v1.30.pdf).

| Document | Notes |
|---|---|
| [HCS300 KEELOQ Code Hopping Encoder datasheet](https://ww1.microchip.com/downloads/en/DeviceDoc/21137G.pdf) | Microchip DS21137G |
| [CC1101 Low-Power Sub-1 GHz RF Transceiver datasheet](https://www.ti.com/lit/ds/symlink/cc1101.pdf) | The transceiver on the E07-433M20S module |
| [RP2350 datasheet](https://datasheets.raspberrypi.com/rp2350/rp2350-datasheet.pdf) | MCU of `sw/kso-fw-rs` |
| [EFR32FG23 Wireless SoC Family Data Sheet](https://www.silabs.com/documents/public/data-sheets/efr32fg23-datasheet.pdf) | Rev. 1.4, SoC of `sw/efr32fg23` |
| [EFR32xG23 Wireless SoC Reference Manual](https://www.silabs.com/documents/public/reference-manuals/efr32xg23-rm.pdf) | Rev. 1.1 |
| [BRD4002A Wireless Pro Kit Mainboard schematic](https://www.silabs.com/documents/public/schematic-files/BRD4002A-A07-schematic.pdf) | Rev. A07 |
| [BRD4265B EFR32FG23B Radio Board (434 MHz, 10 dBm) schematic](https://www.silabs.com/documents/public/schematic-files/BRD4265B-A00-schematic.pdf) | Rev. A00, the copy that was in the repository was A01 |
